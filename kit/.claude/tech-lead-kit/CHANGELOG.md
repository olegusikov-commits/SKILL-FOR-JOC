# Что нового в Tech Lead Kit

## 2.0.0 — 2026-10-19
- **Навигатор `/tl-go`.** Пишешь, что нужно, своими словами — kit предлагает маршрут, ты
  подтверждаешь кнопкой. Без слов — показывает незаконченную работу и следующий шаг.
  `/tl-go new <просьба>` ведёт новую задачу от одной строки до кода, останавливаясь только на
  утверждениях.
- **Уровни глубины:** `mvp` (один короткий документ, одно утверждение, код с тестами главных
  сценариев), `standard`, `full`. Лишние проверки убраны: каждая делается один раз.
- **Требование вместе с тобой:** `/tl-spec new` — интервью по разделам, `/tl-spec complete` —
  дополнить существующее. Вопросы — кнопками, с рекомендованным ответом.
- **План задач с галочками** в дизайне (или в MVP-документе): `/tl-implement` продолжает с места
  остановки в новой сессии. `FLOW.md` в папке задачи — где ты в процессе.
- **SQL:** `/tl-sql build | check | tune`; DBA ищет варианты решения по размеру и причине.
- **Не зависать:** лимиты времени для MCP (`/tl-init` ставит их), защита в каждом запросе
  (`LOCK_TIMEOUT`, `QUERY_GOVERNOR_COST_LIMIT`, `WITH UR`), «проба → расширение», бюджеты и
  `maxTurns` у агентов, пределы всех циклов.
- **Любая тема, любая база:** реестр источников данных (`data-sources.json`) вместо двух
  зашитых серверов; MCP или командная строка.
- **`/tl-explain`** — объяснения и документ проекта со схемами (вместо прежней команды
  tl-project-doc). `/tl-an learn` вместо прежней tl-an-learn.
- Стандарт письма без «воды» (`WRITING.md`); проверка цифр аналитика перед выводом.
- Установщик при обновлении удаляет старые файлы kit (переименованные команды не остаются).
- Встроенный `/init` не нужен — `/tl-init` делает это сам.
